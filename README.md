# 🎥 Chinese Talking Avatar Generator

Upload a portrait + input Chinese script, and automatically generate a talking video with voice and lip sync.

## 🌟 Features

- 🗣️ **Chinese TTS**: Choose between Edge-TTS (Microsoft, stable) or Bark (Suno.ai, more natural)
- 👄 **Lip Sync**: Powered by SadTalker (deep learning-based facial animation)
- 🖼️ **UI Interface**: Built with Gradio for ease of use — no code needed
- 📤 **Video Output**: Realistic talking video with voice and download support

## 🚀 Quick Start (Google Colab)

Click below to run in Colab with full UI:

👉 [Open in Colab](https://colab.research.google.com/github/kevinajex/talking-avatar/blob/main/Chinese_Talking_Avatar.ipynb)


## 🧪 How to Use

1. Upload a clear, front-facing portrait photo
2. Input Chinese text for the speech
3. Choose whether to use Bark (for natural voice)
4. Click **Submit** to auto-generate the talking avatar video
5. Preview and download the result (MP4)

## 🛠️ Tech Stack

- `edge-tts` (Microsoft Azure TTS)
- `bark` (Suno AI)
- `SadTalker` (lip sync & facial animation)
- `Gradio` (for the UI)
